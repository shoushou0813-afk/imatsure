# 画面プロトタイプ

<https://claude.ai/code/artifact/5e57c841-5f78-4d45-bbae-a03cbea7a316>

右上のスイッチが本体。

- **端末: スマホ／PC** — レイアウトの切り替え
- **一覧の型: 高密度（提案）／写真フィード（従来）** — 同じ8件のデータを両方の型で描画し、情報密度の差を比較できる

## サイクル1で測った数字

| 指標 | 高密度（提案） | 写真フィード（従来） |
|---|---|---|
| 1画面あたりの釣行件数（スマホ） | 5.5件 | 0.9件 |
| 8件を見るまでのスクロール | 1.4回 | 8回 |
| 一覧の初期表示データ量 | 約18KB | 約2.4MB |
| 一覧から落とした情報 | 0項目 | — |

いずれもプロトタイプ（幅414px・高さ896px想定）からの**設計上の見込み**であり、実測ではない。
サイクル2で実機計測に置き換える。
