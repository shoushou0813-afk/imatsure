# 収益設計 — 誰から、何に対してお金をもらうか

> フル版（図・表つき）: <https://claude.ai/code/artifact/c70674e4-d428-402b-a22b-fc2029bcc446>

## 結論

1. 釣り場ページの隣に立つ**釣具店・渡船・釣り宿の「公式ボード」を月額で売る**のが本命
2. 個人課金は**「自分の記録を深く使う人」だけ**に売る。閲覧・検索・投稿は永久に無料
3. アフィリエイトと広告は**単体では成立しない**。置くとしても脇役

選定の第一基準は「収益手段が製品価値と同じ方向を向いているか」。
イマツレの価値は見やすさと釣り場を守る姿勢なので、画面を汚す手段はその価値をそのまま削る。

## 運営コスト（MAU 1万想定）

| 項目 | 月額 |
|---|---|
| フロント配信（Cloudflare Pages） | ¥0〜3,000 |
| APIサーバ（Render / Fly.io） | ¥1,000〜4,000 |
| DB（Neon） | ¥0〜3,000 |
| 画像ストレージ（R2・転送無料） | ¥100〜1,000 |
| ドメイン | ¥150 |
| **合計** | **¥2,000〜11,000** |

**重要な発見**: この規模ではサーバ代がほとんどかからない。
つまり収益設計の目的は赤字回避ではなく、**続ける理由をつくることと自分の時間に値段をつけること**。

## 無料とプレミアムの線引き

売るのは「みんなのための情報」ではなく**「自分のためのデータ」**。

| 機能 | 無料 | プレミアム ¥480／月 |
|---|---|---|
| 閲覧・検索・フィルタ | 無制限 | 同じ |
| 投稿・スレッド・ルール | 無制限 | 同じ |
| 写真 | 1釣行3枚・1年で圧縮 | 無制限・原寸保管 |
| 自分の釣行分析 | 年間合計だけ | 潮×時間帯のヒートマップ、タックル別成績 |
| 通知 | — | フォロー釣り場で狙いの魚が釣れたら |
| CSV書き出し | — | 全釣行 |

## やらないと決めること

- 詳細検索・過去データの有料化（差別化の中心を自分で潰す）
- 釣果の個票データ販売（釣り場を守る姿勢と矛盾する）
- 位置情報の外部提供
- 競争を煽る大会・ランキングのスポンサー
- 自動配信のディスプレイ広告の全面展開
- 投稿数に応じたポイント還元（捏造投稿を呼び込む）

## フェーズ

| Phase | 期間 | 内容 | 月商 |
|---|---|---|---|
| A | 0〜6か月 | 収益ゼロ。1つの釣り場に集中し、他人の投稿が自然発生するまで待つ | ¥0 |
| B | 6〜12か月 | 店舗3件＋アフィリエイト。ここで黒字化 | ¥25,000 |
| C | 12〜24か月 | エリア拡大、店舗20件＋プレミアム200人 | ¥250,000 |
| D | 24か月〜 | 自治体・漁協との連携。収益より参入障壁 | — |

数字はすべて仮説。使い方は「当てる」ことではなく、**Phase Bで店舗3件が取れなければモデルを疑う**という判断基準。

## 法務チェックリスト

| 項目 | いつ |
|---|---|
| 特定商取引法に基づく表記 | 課金開始前（個人事業でも必要） |
| 利用規約・プライバシーポリシー | 公開前（位置情報を扱うので必須） |
| ステマ規制（景表法） | アフィリエイト設置時。「広告」「PR」明示 |
| 決済（Stripe 3.6%） | 課金開始時 |
| インボイス登録 | 店舗に請求書を出すとき |
| 資金決済法 | 投げ銭を作るとき（都度課金なら回避できる） |

※法務の助言ではありません。実際の内容を持って専門家に確認してください。
